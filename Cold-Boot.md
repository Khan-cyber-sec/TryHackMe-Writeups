## 🛠️ Key Hardware Concepts Learned
- *Motherboard (MOBO):* Central hub connecting and routing communication between all components.
- *CPU & Cooler:* Main processor and heat dissipation unit.
- *RAM vs Storage:* Temporary high-speed memory vs long-term storage (NVMe SSD over legacy mechanical HDDs for startup speed).
- *GPU:* Dedicated processing unit for rendering visual output to the display.
